Reports Groovy variable declarations using the def or var keyword when an explicit type can be inferred.

Replacing dynamic def and var declarations with explicit static types enhances type safety, eliminates ambiguity, and maximizes productivity by optimizing IDE code analysis, autocompletion, and refactoring capabilities.

A quick-fix is provided to replace def or var with the inferred explicit type.

Example:


def name = "MongoDB"
var port = 27017

After the fix is applied:


String name = "MongoDB"
Integer port = 27017

Only declarations where a non-Object, uniform explicit type can be inferred across all declared variables will be reported.
